Voice control
Get Started

You can control the devices that you connected to the Guardian TE app with Amazon Echo.

How to setup

Voice commands
For <DeviceName>, please enter the name you gave to the device on this app.

General Information
  • Alexa, ask Guardian Technologies.
Control device
  • Alexa, ask Guardian Technologies to turn on <DeviceName>.
  • Alexa, ask Guardian Technologies to turn off <DeviceName>.
  • Alexa, ask Guardian Technologies to set the fan speed of <DeviceName> to <1-5 or auto>.
  • Alexa, ask Guardian Technologies to turn on the uv mode of <DeviceName>.
  • Alexa, ask Guardian Technologies to turn off the uv mode of <DeviceName>.
  • Alexa, ask Guardian Technologies to set the timer of <DeviceName> for <1-8> hours.
  • Alexa, ask Guardian Technologies to turn off the timer of <DeviceName>.
Ask device status
  • Alexa, ask Guardian Technologies what's the fan speed of <DeviceName>.
  • Alexa, ask Guardian Technologies for the fan speed of <DeviceName>.
  • Alexa, ask Guardian Technologies what's the uv mode of <DeviceName>.
  • Alexa, ask Guardian Technologies for the uv mode of <DeviceName>.
  • Alexa, ask Guardian Technologies what's the timer of <DeviceName>.
  • Alexa, ask Guardian Technologies for the timer of <DeviceName>.
  • Alexa, ask Guardian Technologies how's the air quality of <DeviceName>.
  • Alexa, ask Guardian Technologies for the air quality of <DeviceName>.
  • Alexa, ask Guardian Technologies what's the particulate matter of <DeviceName>.
  • Alexa, ask Guardian Technologies for the particulate matter of <DeviceName>.
  • Alexa, ask Guardian Technologies how's the filter life of <DeviceName>.
  • Alexa, ask Guardian Technologies for the filter life of <DeviceName>.
  • Alexa, ask Guardian Technologies how's the UV life of <DeviceName>.
  • Alexa, ask Guardian Technologies for the UV life of <DeviceName>.
  • Alexa, ask Guardian Technologies about <DeviceName>.
  • Alexa, ask Guardian Technologies for <DeviceName>.
