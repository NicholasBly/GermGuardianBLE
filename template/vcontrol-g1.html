Voice control
Get Started

You can control the devices that you connected to the Guardian TE app with Google Home or Android.

How to setup

Voice commands
For <DeviceName>, please enter the name you gave to the device on this app.

General Information
  • OK Google, talk to Guardian Technologies.
Control device
  • OK Google, talk to Guardian Technologies to turn on <DeviceName>.
  • OK Google, talk to Guardian Technologies to turn off <DeviceName>.
  • OK Google, talk to Guardian Technologies to set the fan speed of <DeviceName> to <1-5 or auto>.
  • OK Google, talk to Guardian Technologies to turn on the uv mode of <DeviceName>.
  • OK Google, talk to Guardian Technologies to turn off the uv mode of <DeviceName>.
  • OK Google, talk to Guardian Technologies to set the timer of <DeviceName> for <1-8> hours.
  • OK Google, talk to Guardian Technologies to turn off the timer of <DeviceName>.
Ask device status
  • OK Google, talk to Guardian Technologies to let me know the fan speed of <DeviceName>.
  • OK Google, talk to Guardian Technologies to tell me the fan speed of <DeviceName>.
  • OK Google, talk to Guardian Technologies to let me know the uv mode of <DeviceName>.
  • OK Google, talk to Guardian Technologies to tell me the uv mode of <DeviceName>.
  • OK Google, talk to Guardian Technologies to let me know the timer of <DeviceName>.
  • OK Google, talk to Guardian Technologies to tell me the timer of <DeviceName>.
  • OK Google, talk to Guardian Technologies to let me know the air quality of <DeviceName>.
  • OK Google, talk to Guardian Technologies to tell me the air quality of <DeviceName>.
  • OK Google, talk to Guardian Technologies to let me know the particulate matter of <DeviceName>.
  • OK Google, talk to Guardian Technologies to tell me the particulate matter of <DeviceName>.
  • OK Google, talk to Guardian Technologies to let me know the filter life of <DeviceName>.
  • OK Google, talk to Guardian Technologies to tell me the filter life of <DeviceName>.
  • OK Google, talk to Guardian Technologies to let me know the UV life of <DeviceName>.
  • OK Google, talk to Guardian Technologies to tell me the UV life of <DeviceName>.
  • OK Google, talk to Guardian Technologies to give me a status report of <DeviceName>.
  • OK Google, talk to Guardian Technologies to give me a status update of <DeviceName>.
